# 🎬 İzleme Listesi (Watchlist)

TMDB (The Movie Database) destekli, modern **Neon Yeşil & Mor** sinematik temalı kişisel film ve dizi izleme listesi web uygulaması.

---

## 🌟 Özellikler

- **🎬 Filmler & 📺 Diziler:** TMDB veritabanı üzerinden dilediğiniz film veya diziyi anında arama ve tek tıkla listeye ekleme.
- **✅ Kalıcı "✓ İzledim" İşaretleme:** İçerikleri tek tıkla izlendi olarak işaretleme ve `✅ İzlendi` sekmesinde topluca görüntüleme. Sayfa yenilense veya kapatılsa dahi tüm durumlar `localStorage` ile kalıcı olarak korunur.
- **🎨 Neon Yeşil & Mor Tasarım:** Cyberpunk / modern obsidian karanlık tema ve cam efekti (glassmorphism).
- **📝 Detay & Not Ekleme:** Kişisel puanlama (1-10 ⭐) ve not yazabilme.

---

## 🚀 Kurulum ve Çalıştırma

1. Projeyi bilgisayarınıza indirin veya klonlayın:
   ```bash
   git clone <REPO_URL>
   cd izleme-listesi
   ```

2. Doğrudan `index.html` dosyasını herhangi bir tarayıcıda açın veya yerel sunucu ile çalıştırın:
   ```bash
   npx serve .
   ```
   Tarayıcınızda `http://localhost:3000` adresine gidin.

---

## 🛠️ Teknolojiler
- HTML5 & CSS3 (Vanilla CSS, Glassmorphism, CSS Variables)
- Vanilla JavaScript (ES6+, LocalStorage, Fetch API)
- TMDB API v3
